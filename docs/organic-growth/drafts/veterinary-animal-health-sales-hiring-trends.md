## Changes over time

No comparable historical snapshot with a fixed employer cohort and verified source coverage is available for this first edition. We cannot claim hiring growth, a decline, seasonality or a change in demand. Future reports should distinguish new-source coverage, classification changes and collection changes from genuine changes within a stable tracked sample. No salary or earnings estimates are included.

## Methodology and limits

Counts were read from ROOK’s public collection summaries. The existing collection code filters active, approved, US-eligible listings and groups exact requisition/source identities; employers are counted within each collection. This audit verified the displayed totals and inspected that code, but did not revalidate every vacancy against the employer on this date. Source verification is inherited from ROOK’s existing ingestion process, which was not changed. The observations are sequential within one collection run, not an atomic database snapshot.

Only broad, pre-existing collections with at least 20 opportunities and three represented employers may be reported. There are no employer rankings, city-by-specialty breakdowns, exact job titles, source identifiers, application links, cross-tabulations or subtraction tables. A suppressed cell is withheld in full. Geographic distribution beyond the existing Florida collections is unavailable in this edition.

The tracked sample is not the entire employment market. Counts can move because listings close, sources refresh, sources are added or classification changes. An advertised role is not a verified hire. This report is a descriptive baseline, not a forecast. Refresh and reapprove statistics if the publication date changes.
